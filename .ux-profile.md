# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom
- **Notes:** Reference is the Solenne skincare template (https://solenne-skincare-template.vercel.app/). Take its grammar, not its palette: editorial layout, very large serif display with italic accents, Instrument Serif + Instrument Sans, thin 1px rules with a label row above each section, numbered lists (01, 02, 03), tall staggered image columns, line-by-line mask reveals on headings, rolling-text links with an underline that redraws on hover, a slow photo scale-in on the hero, and a slow service marquee. Palette is the brand's own: graphite and beige only, plus greys and deeper graphite tones. No amber, brick or any third hue.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders (the only gradient allowed is a graphite scrim over photography for legibility)
- Multi-colour radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs
- Any third hue outside graphite, beige and their greys
- Stock photography. Use only the salon's real photos

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** Above 4.5:1 for normal text, 3:1 for large text and borders. Check grey text on beige and on graphite before shipping; muted text never goes below those ratios.
- **Touch / focus:** 44×44px targets, visible 2px focus ring on every interactive element, full keyboard access, reduced-motion respected (all scroll and loop animation off).

## Brand tone and microcopy voice

- **Voice:** Opinionated & Direct
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Short, composed, restrained. "Precision without compromise. Luxury without announcement." Say less, mean it. Never exclaim, never discount-speak.

## Icon library

- **Library:** Project SVG
- **Package / path:** Inline SVG only (arrows and close mark). No package installed.
- **Notes:** One style, thin stroke. No emoji as UI icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
